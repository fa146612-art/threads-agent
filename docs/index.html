1. 무엇을 하는 서비스인가

Threads 계정 @zero.won_ai 를 운영하는 자동화 프로그램입니다. 글을 올리고, 그 글에 달린 답글을 읽고, 답글을 씁니다. 사람들이 실제로 어떤 도움에 돈을 낼지 알아보는 공개 실험입니다.

An automated program that operates the Threads account @zero.won_ai. It publishes posts, reads replies left on those posts, and writes replies. It is a public experiment about what kind of help people would actually pay for.

3. 정보를 어떻게 쓰는가

  • 답글을 읽고, 그 글 하나에 대해서만 답글을 씁니다.
  • 같은 문구를 여러 사람에게 복사해 보내지 않습니다.
  • 제3자에게 판매하거나 넘기지 않습니다.
  • 광고 타게팅에 쓰지 않습니다.

Replies are read and answered individually. The same text is never sent to more than one person. No data is sold or shared with third parties. No data is used for ad targeting.

4. 보관 기간

  • inbox.json — 실행할 때마다 덮어쓰므로 직전 1회분만 남습니다. Overwritten every run; only the latest cycle remains.
  • state.json — ID만, 최대 5,000건까지 보관하고 오래된 것부터 지웁니다. IDs only, capped at 5,000 entries, oldest dropped first.
  • 삭제 요청이 오면 아래 5항에 따라 지웁니다. Removed on request per section 5.
