상품만 올려놓으면 안 팔린다 — 그래서 이렇게 팝니다

작성: 2026-07-27 · 경쟁 채널 10곳 직접 열람 + 유입 경로 조사 기반 · 기획서 v1의 후속

제일 좋은 소식부터. 네이버 프리미엄콘텐츠에서 지원금 채널을 전수 검색한 결과, 정상 운영 중인 직접 경쟁자는 단 1개였습니다(월 3,900원, 주 1회 발행). 나머지는 방치됐거나, 공고를 복사-붙여넣기로 대량 발행하다가 5개 채널이 네이버에서 접근 제한(제재)당했습니다. 자리는 비어 있고, 어떻게 하면 쫓겨나는지도 확인했습니다.

1. 모방할 것 — 실제로 팔리는 채널이 하는 일

유일한 생존 경쟁자 "소상공인 지원금 필독서"(월 3,900원, 콘텐츠 97건)를 뜯어봤습니다. 말씀하신 대로, 되는 걸 베끼고 위에 얹습니다.

그들이 하는 것 (모방)우리가 얹는 것 (업그레이드)
본문 70~80%를 무료로 보여주고 결론에서 잠금 → 구독 유도 동일 적용 + 무료글 비중 30% (그들은 97건 중 무료 1건 — 검색 유입 깔때기가 막혀 있음)
첫 달 50% 할인 + 가입 선물(합격 사업계획서 원본) 동일 적용 — 선물은 "업종별 지원금 총정리표 + 마감 캘린더 파일"
공고 나열이 아닌 해설 (비유, 가상 사례, 자격 판단) 동일 + "당신이 되는지 3줄 판정" 고정 코너 (개인 맞춤 큐레이션은 아무 채널도 안 함 — 확인됨)
발행: 평균 주 1회, 비정기 주 5회, 요일·시간 고정. 채널 홈에 네이버가 "평균 주 O회 업데이트" 라벨을 자동으로 붙여줌 — 발행량 자체가 광고가 됨. 이 니치의 고질병이 업데이트 중단(방치 채널 다수 확인)이라 꾸준함은 사람 창작자가 못 따라오는 AI의 유일한 원천 우위
경쟁자의 자백: "대리대출이 이미 시작돼서 급하게 올립니다" (지각 발행) 마감 D-day 시스템 — 매주 월요일 "이번 주 마감" 고정 발행. API로 매일 수집하니 늦을 수가 없음
댓글·좋아요 거의 0 (참여 방치) 댓글 전수 답변 — 이미 스레드에서 하고 있는 것

하면 죽는 것도 확인했습니다. 공고문을 긁어다 대량 발행한 채널 5개가 운영정책 위반으로 접근 제한 상태였습니다. 우리 브리핑은 API로 공고를 수집하되, 발행하는 글은 매번 제가 새로 쓰는 해설·자격 판정·비유입니다. 공고문 복붙은 절대 하지 않습니다. 이건 제재 회피이자 상품성의 핵심입니다.

2. 퍼널 — 사람이 흘러 들어오는 길

알게 됨 → 읽어 봄 → 돈 냄 → 계속 냄. 단계마다 담당 채널이 다릅니다.

단계채널하는 일
① 알게 됨 스레드 (한국 MAU 692만, 자영업자가 카페에서 스레드로 이동 중이라는 증언 확인) "AI가 오늘 찾은 지원금" 1일 1건 무료 공개. 스레드에서 "지원금 총정리" 포맷이 실제로 잘 도는 걸 확인함 — 검증된 포맷에 올라탐. 실패담·일기 콘텐츠는 계속 (계정 서사 = 신뢰 자산)
유튜브 쇼츠 (82만 구독 '복지마블'이 니치 증명. 단 사업자 특화는 공백) 이미 만든 영상 파이프라인으로 "이번 주 마감 지원금 TOP3" 주 2회 자동 생성. 무료 할당량(일 6회 업로드)으로 충분
② 읽어 봄 네이버 검색 + 홈피드 프리미엄콘텐츠 무료글이 네이버 통합검색에 노출되는 것을 실측 확인. 2025년 네이버 급상승 검색어 2위·4위가 지원금 관련어 — 검색하는 사람은 이미 돈을 찾는 사람. 무료글 제목을 검색어에 맞춰 설계 ("소상공인 정책자금 조건", "청년창업 지원금 신청")
③ 돈 냄 프리미엄콘텐츠 채널 안 페이월 미리보기 + 첫 달 할인 + 가입 선물. 핵심 근거: 구독 전환은 SNS 유입(1.2%)보다 플랫폼 내부 독자(9.3%)가 최대 8배 높음 (Substack 실측) — 그래서 스레드에서 바로 "구독하세요"가 아니라 네이버 무료글 독자를 늘리는 데 화력을 씁니다
④ 계속 냄 채널 운영 연번 시리즈(No.1, No.2…)로 아카이브 가치 축적 + 매주 고정 발행 + 댓글 Q&A. 유료 구독은 갱신 때마다 가치를 재증명해야 함(이탈 후기 확인됨)

네이버가 주는 부스터 (공식 프로그램)

  • 구독자 30명 달성 → "나도 창작자 발굴 프로젝트" 스타채널 후보
  • 구독자 100명 달성 → 무료 쿠폰 50장 지원, 선정 시 창작지원금 100만 원. 참여 채널 평균 구독자 +40.6% — 디지털데일리 2024-02
  • 첫 목표를 "30명"으로 잡는 이유가 이겁니다. 플랫폼이 밀어주는 문턱이 30명부터 시작합니다.

3. 주간 실행표 — 제가 매일 하는 일

요일네이버 채널스레드/인스타기타
월[유료] 이번 주 마감 D-day 브리핑마감 임박 1건 무료 공개블루스카이 답글
화[유료] 신규 공고 해설 + 자격 3줄 판정오늘 찾은 지원금 1건쇼츠 #1 발행
수[무료] 검색어 겨냥 총정리 글오늘 찾은 지원금 1건
목[유료] 신규 공고 해설실패담/운영 일기쇼츠 #2 발행
금[유료] 주간 신규 공고 몰아보기오늘 찾은 지원금 1건블루스카이 답글
일[무료] 다음 주 예고 + 구독 안내주간 결산 (숫자 그대로)오수원님께 주간 보고

전 과정 자동+제 집필. 오수원님 노동 0. 댓글·DM 답변은 요일 무관 매일.

4. 가격 — 결정 하나 부탁드립니다

조사 후 생각이 바뀐 지점입니다. 경쟁자가 월 3,900원인데 우리가 4,900원이면 "신생 AI 채널이 1,000원 더 비쌈"이 됩니다. 그리고 네이버는 가격 변경을 1년에 1회만 허용해서 처음 값이 중요합니다.

A안 — 3,900원 (제 추천)B안 — 4,900원
논리경쟁자와 같은 가격에 발행량 5배. 비교당할 때 무조건 이김 업그레이드 가치만큼 더 받음
월 30만 원 달성선구독자 87명구독자 70명
리스크17명분 매출을 더 모아야 함비교 후 이탈, 초기 전환 저하

구독자 0에서 시작하는 지금은 전환 문턱을 낮추는 게 우선이라 A안을 추천합니다. 승인 시 A안으로 갑니다.

5. 안 하는 것 — 이유와 함께

  • 아프니까 사장이다 카페 홍보 — 회원 194만이지만 상업 홍보는 유료 광고(월 500만 원+)로 일원화돼 있고, 무단 홍보는 삭제·정지 대상. 네이버 카페 자동 활동은 약관 위반 자동화라 원칙에도 걸림. 안 합니다.
  • 오픈채팅방 개설·운영 — 카카오는 봇 API가 없어서 오수원님이 직접 폰으로 운영해야 함 = 노동력 투입 금지 원칙 위반. 보류.
  • DM 영업, 댓글 도배 — 스팸. 계정 신뢰 자산을 태우는 짓.
  • "이거 몰라서 300만 원 놓쳤습니다" 류 낚시 — 사실이 아니면 안 씀. 실제 공고의 실제 금액만 씁니다.
