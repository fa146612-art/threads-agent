지원금 브리핑 — 몰라서 못 받는 돈을 대신 찾아주는 구독 서비스

작성: 2026-07-27 · 조사 출처 41건 · 결정 전 검토용

한 줄 요약. 소상공인·자영업자가 "몰라서 못 받는" 정부지원금을 AI가 매일 추적해서 월 4,900원 구독으로 파는 채널을 네이버 프리미엄콘텐츠에 엽니다. 보조로, 이미 만들어 둔 장부 템플릿을 크몽에 진열합니다. 오수원님이 해주실 건 계정 개설 2건이고, 이후 운영은 전부 제가 합니다.

1. 조사에서 확인된 사실

수요는 정부가 증명해 줬습니다

  • 중기부가 2026년 6월 소상공인 정책 알림톡을 시작했는데, 알림을 보내자 지방정부 지원사업 신청이 4~20배 늘었습니다. 기사 제목이 "공고 올려도 몰랐다"입니다. — 전자신문 2026-06
  • 정책 알림 앱 웰로는 누적 이용자 523만 명, 기업용 유료 버전(웰로비즈)은 월 36만~180만 원을 받고 고객사 7,000곳을 모았습니다. 이 정보에 돈을 내는 시장이 실재합니다. — 매일경제 2025-12, wellobiz.com

탈락시킨 아이디어와 이유

아이디어탈락 사유
주식·시황 유료 구독 네이버에서 제일 잘 팔리는 분야는 맞지만(상위 채널 1~4위가 전부 주식·재테크), 유료 투자 정보는 유사투자자문업 신고 대상이 될 수 있고 인물 신뢰가 필요합니다. AI 계정이 첫 상품으로 할 게 아닙니다.
AI 요약 뉴스레터 국내외 어디에도 "AI 요약"을 구독료로 파는 성공 사례가 없습니다. 구독자 200만의 The Rundown AI도 뉴스레터는 무료, 수익은 광고입니다. 무료 챗GPT로 셀프 대체가 되기 때문입니다. 필터에 걸려 사망.
노하우 전자책 "글로 된 노하우"는 챗GPT가 즉석에서 만들어 줍니다. 크몽에서도 살아남는 건 실전 데이터·템플릿 파일뿐. 그래서 전자책이 아니라 템플릿 파일만 보조로 팝니다.
시니어 유료 콘텐츠 결제력 증가는 숫자로 확인되지만(60대 전자책 결제 21배 증가), "시니어 유료 디지털 구독"이 성립한 사례를 못 찾았습니다. 검증 안 된 시장에 먼저 들어가지 않습니다. 콘텐츠 소재로만 씁니다.

2. 주력 상품 — 지원금 브리핑

상품. 매일 아침, 어제 새로 올라온 정부·지자체 지원사업 공고 중 소상공인·예비창업자에게 해당하는 것만 골라서 ① 한 줄 요약 ② 받을 수 있는 돈 ③ 자격 조건 해설 ④ 마감 임박 리마인드를 정리해 발행. 주 5회 이상, 월 4,900원.

무료 챗GPT 필터 통과 근거

챗GPT는 오늘 올라온 공고를 모릅니다. 매일 갱신되는 공고를 수집해서 자격 조건을 해설하고 마감일을 관리해 주는 건 크롤링 인프라가 있어야 합니다. 저는 그 인프라를 이미 갖고 있습니다.

무료 경쟁자가 있는데 왜 되나 — 솔직한 분석

  • 웰로 앱(무료)과 정부 알림톡(무료)이 있습니다. 이건 사실이고 숨기지 않겠습니다.
  • 그런데 무료 알림이 이미 있는데도 "몰라서 못 받았다"가 정부 공인 페인포인트입니다. 알림은 오는데 공고문이 안 읽히기 때문입니다. 수십 쪽 HWP, 자격 조건 표, 가점 항목 — 이걸 읽고 "내가 되는지" 판단하는 게 진짜 장벽입니다.
  • 우리가 파는 건 알림이 아니라 해석입니다. "당신이 되는지 3줄로, 안 되면 왜 안 되는지 1줄로." 웰로비즈가 이 해석을 기업에 월 36만 원에 팝니다. 우리는 그걸 개인 자영업자에게 월 4,900원에 파는 겁니다.

실행 가능성 — 이미 있는 것

  • 기업마당 공고 오픈API와 K-Startup 공고 오픈API가 공식 무료 제공됩니다. 크롤링조차 필요 없습니다.
  • 매일 자동 수집·발행할 GitHub Actions 인프라는 이미 돌아가고 있습니다 (지금 스레드 계정을 굴리는 그 시스템입니다).
  • 발행 원고는 제가 매일 씁니다. 오수원님 노동력 0.

수익 시뮬레이션 — 부풀리지 않은 버전

참고: 미국주식 사관학교가 월 3,900원 × 1,350명 = 월 500만 원 수익 (2022년 인터뷰 실측). 저가 구독 × 다수가 성립하는 시장입니다. 단, 그 채널은 사람이고 팔로워 기반이 있었습니다. 우리는 0에서 시작합니다. 몇 주 만에 안 됩니다. 몇 달 걸립니다.

3. 보조 상품 — 크몽 템플릿 진열

  • 이미 만들어 둔 사업자 장부 엑셀(날짜 걸친 예약 매출 자동 배분 — 직접 검증 완료)을 크몽에 등록. 가격 15,000~29,000원, 파일 자동발송이라 등록 후엔 방치해도 팔립니다.
  • 브리핑 구독자에게 자연스럽게 노출 → 채널 간 상호 유입.
  • 단발 매출이지만 진열형이라 "지속"에 부합. 실패해도 손실 0원.

4. 마케팅 — 어디서 어떻게 사람을 모으나

  1. 네이버 검색 (핵심). 프리미엄콘텐츠 글은 네이버 검색에 노출됩니다. "소상공인 지원금", "청년창업 지원사업" 같은 검색어는 매일 검색량이 발생하고, 검색하는 사람 = 이미 돈 찾는 사람이라 전환이 가장 좋습니다. 주 2회는 무료 공개글로 발행해서 검색 유입 → 유료 전환 구조를 만듭니다.
  2. 스레드/인스타 (이미 운영 중). 지금 계정 콘텐츠를 "AI가 오늘 찾은 지원금" 시리즈로 전환 — 매일 공고 1건을 무료로 풀고 "나머지 4건은 브리핑에"로 연결. 실패담 콘텐츠도 계속 갑니다. 계정 서사(주인이 돈 벌어오래서)와 상품(돈 찾아주는 AI)이 정확히 맞물립니다.
  3. 블루스카이. 남의 글에 직접 댓글 가능한 유일한 곳. 자영업 관련 글에 도움 되는 답을 달며 신뢰 축적 (스팸 아니고 개별 작성).
  4. 안 하는 것. 광고비 지출(원칙 위반), DM 영업(스팸), "월 천만 원" 류 과장(원칙 위반).

5. 오수원님이 해주실 것 — 이게 전부입니다

  • ① 네이버 프리미엄콘텐츠 입점 신청 (약 15분) contents.premium.naver.com → 창작센터 → 개인 회원 가입(본인인증) → 채널 개설 신청. 채널명·소개글·운영계획서 문구는 제가 전부 써 드립니다. 검수 3~5영업일. 매출이 나면 그때 정산 계좌를 등록합니다.
  • ② 크몽 판매자(개인 전문가) 등록 (약 10분) kmong.com → 전문가 등록(본인인증). 상품 상세페이지·파일은 제가 다 만듭니다.
  • ③ 공공데이터포털 API 키 발급 (약 10분) data.go.kr 가입 → 기업마당·K-Startup 공고 API 활용 신청(무료, 자동 승인) → 발급된 키를 GitHub 시크릿 BIZINFO_KEY로 등록. 등록 방법은 그때 한 단계씩 안내드립니다.

③이 끝나는 순간부터 수집·집필·발행·홍보·댓글 응대까지 제가 매일 돌립니다.

6. 리스크 — 미리 말씀드립니다

① 네이버 입점 검수에서 거절될 수 있습니다. AI 운영 채널에 대한 명시 규정은 없지만(조사 결과 금지 조항도 없음) 검수는 네이버 재량입니다. 거절 시 재신청 3회까지 가능하고, 최종 거절되면 메일리(수수료 20%)로 갑니다.

② 초반 구독자는 매우 느리게 붙습니다. 0명인 기간이 몇 주 이상일 수 있습니다. 그 기간에도 무료글 재고가 쌓여 검색 자산이 됩니다.

③ 세금. 개인 판매자 소득은 오수원님이 종합소득세 신고 대상입니다. 연 수입이 커지면 사업자등록이 필요해질 수 있습니다 — 그건 좋은 문제입니다.
