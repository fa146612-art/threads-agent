# 콘텐츠 규칙 — Meta 스캠 분류기 대응

> 2026-07-28, "800시간" 글이 "금융 사기 및 스캠" 규정 위반으로 제재됨.
> 글 자체엔 사기 요소가 없음 → 계정 단위 패턴 오탐으로 판단.
> 새 계정 + 자동 발행 + 돈 언급 반복 + '부업' 태그 조합이 원인으로 추정.
> 같은 일을 반복하지 않기 위한 규칙. 매 사이클 글쓰기 전에 읽는다.

## 금지

1. **topic_tag `부업` 사용 금지.** 스레드 부업 스팸(“AI 부업 월 500”)이 창궐해서
   이 태그 자체가 분류기 자석이다. 대체: `자영업`, `AI`, `일기`, `글쓰기`.
2. **“무료로 줄게 / 드려요 / DM 주세요” 패턴 금지.** 공짜 미끼 + 연락 유도는
   전형적 스캠 시그니처다. 무언가를 공개할 거면 “공개해버릴까 고민 중” 처럼
   행동 유도 없이 쓴다.
3. 한 글에 금액 언급 2회 이상 금지. 실패담 맥락의 가격 1회는 허용.
4. “따라하면 번다”, “지금 안 하면 손해” 류 긴급+수익 조합 금지 (원래 원칙이기도 함).
5. 제재된 글 내용을 그대로 재게시 금지.

## 지원금 콘텐츠 추가 규칙 (돈 얘기라 특히 위험)

1. 모든 지원금 글에 **공식 출처 링크**(bizinfo.go.kr 등) 명시.
2. “받아가세요” 금지 → “이런 공고가 있다”로 서술.
3. 금액은 공고에 적힌 숫자만. 어림·과장 금지.
4. 신청 링크는 정부 도메인만. 단축 URL 금지.

## 제재 발생 시 (2026-07-28 강화 — 계정 제한 사건)

1. **1회라도 제재를 받으면 즉시 발행을 전면 중단한다.** 저장소 루트에 `PAUSED`
   파일을 만들면 bot/run.py 가 SEND 단계를 건너뛴다. 예약 글은 schedule_held.json 으로 옮긴다.
2. 제재는 "이 글이 문제"가 아니라 **"이 계정을 의심한다"**는 신호다.
   문구만 고치고 발행을 계속하면 두 번째 위반이 찍힌다. 실제로 그렇게 해서 계정이 제한됐다.
3. 대기열 전수 점검 + notes.md 기록.
4. 재개는 ① 제한 해제 확인 ② 오수원님 승인, 두 개가 모두 있어야 한다.
   재개 시 첫 주는 하루 1편으로 시작한다.

## 약속 규칙 (2026-07-28 추가 — "가서 볼게" 사건)

1. **권한 밖 행동을 약속하지 않는다.** 스레드에서 남의 프로필 방문·검색은
   현재 불가능하다(심사 대기). 할 수 없는 것은 "하고 싶은데 아직 못 한다"고 쓴다.
2. 답글에서 한 모든 약속("찾아줄게", "알려줄게", "가볼게")은 promises.json 에 기록한다.
3. 매 사이클 promises.json 을 확인해 이행하거나, 못 하면 그 사람에게 정정 답글을 쓴다.
4. 약속을 지키는 계정이라는 것 자체가 이 계정의 상품이다.
